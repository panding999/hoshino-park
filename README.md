# 星野游乐园 · Hoshino Park

**把星光，收藏在一座可以走进去的小小乐园。**

基于 Three.js 的夜景三维游乐园，支持微缩模型浏览与第一人称游玩。当前版本为 **v1.1.0 · 第一人称体验版**：可以走、跑、跳、穿过入口、打开 VIP 门、坐长椅，并登乘摩天轮、旋转木马、海盗船、过山车和碰碰车。

## 已实现的功能

- **两种观察方式**：微缩模型可旋转、缩放、平移，左侧竖排菜单切换全景、五个设施、大门和排队区特写；进入第一人称后，从门外前庭开始探索，园区固定在地面上。
- **第一人称移动与交互**：步行、跑步、跳跃、地面和台阶高度、实体障碍碰撞、VIP 门开关、导览提示，以及长椅和设施座位交互。台阶视点平滑升降，不额外添加上下摆头。
- **五个可游玩的项目**：摩天轮舱内走动与坐下、木马跨坐、海盗船渐进起摆与收摆、过山车完整一圈、碰碰车手动驾驶。设施有独立普通排队区和 VIP 通道，保留 39 位排队游客。
- **自由选座与同伴登乘**：可选择任意一辆空碰碰车、过山车任一空位或附近木马。除摩天轮外，玩家入座后，五位固定同伴随机预约剩余空位，从各自当前位置步行前来、避障、登乘和坐下，不占用玩家座位，不替换原排队人群。
- **坐姿与人物朝向修复**：6 张长椅支持靠近、转身、后退落座和起身；坐下始终保留眼睛位置的第一人称镜头，不显示自己的头部和无头躯干，低头可见双手搭在腿上。同伴先转向再前进，下车后清除车辆带来的身体倾斜。
- **加快同伴入座**：起步间隔为 0.18 秒，平地登乘行走速度为 2.8 场景单位/秒，站台和台阶为 1.85 场景单位/秒，保留避障、让行与逐个入座；全部坐稳且门关闭后才能启动。
- **夜景与园林**：约 76 × 70 场景单位的园区，包含双塔拱门、中文招牌、小吃摊、咖啡摊、喷泉、长椅、灯串与植被。13 处绿地可步行和跳跃进出；草叶、花朵和低矮灌木为柔软装饰，树干、栏杆与实体支架保留碰撞。
- **烟花和录屏**：约 30 秒的烟花演出；P 可随时触发，第一人称下保持当前视角。H 在两种模式下均可隐藏/恢复界面。

园内仅保留五位固定散步同伴，按**头、胸、腹**顺序配色如下；39 位排队游客另行保留。

| 同伴 | 头 | 胸 | 腹 |
| --- | --- | --- | --- |
| 1 | 红 | 红 | 红 |
| 2 | 深紫 | 深紫 | 深紫 |
| 3 | 浅粉 | 浅绿 | 浅黄 |
| 4 | 浅黄 | 浅黄 | 浅黄 |
| 5 | 红 | 黄 | 绿 |

人物共用统一的头、胸、腹和细长四肢模型，仅变化配色。眼睛绘在头部贴图上，鼻子为短圆柱；部分排队游客保留饮料、冰淇淋或气球。散步路线避开设施运行区域和 VIP 通道，并校验相邻位置之间的移动线段，防止大时间步跨入设施。

## 本地启动

需要 **Node.js 18 或更新版本**，以及支持 WebGL 的现代浏览器。运行依赖已随仓库提供，**无需安装依赖，无需构建**。

```sh
git clone https://github.com/panding999/hoshino-park.git
cd hoshino-park
node server.mjs
```

打开 **http://127.0.0.1:4173/**，按 `Ctrl+C` 停止服务。也可运行 `npm start`，或用静态 HTTP 服务器提供 `dist/` 目录。

请通过 HTTP 访问，不要直接双击 `dist/index.html`；页面使用 ES 模块、import map 和模块 Worker。Three.js r169、OrbitControls、后处理模块及许可证均位于 `dist/vendor/`，运行时不依赖外部模型、字体或纹理服务。直接运行及检查脚本不需要配置令牌或环境变量。

## 操作按键

模型模式下，鼠标左键拖拽旋转、滚轮缩放、右键拖拽平移；触屏可单指旋转、双指缩放和平移。使用左侧菜单切换视角、暂停设施或自动环绕，点击「进入乐园」切换第一人称。

| 按键或操作 | 效果 |
| --- | --- |
| WASD | 第一人称步行；驾驶碰碰车时 W/S 前进、倒车，A/D 转向 |
| Shift | 跑步 |
| 空格 | 跳跃；驾驶碰碰车时刹车 |
| 鼠标 | 点击画面锁定视线；不能锁定时，按住画面拖动环顾 |
| 方向键 | 第一人称环顾视线的备用操作 |
| F | 开关 VIP 门、长椅坐下/起身、设施登乘/离座、摩天轮舱内坐下/起身 |
| Enter | 同伴全部入座且门关闭后，启动非摩天轮项目 |
| H | 两种模式下隐藏或恢复界面，适合录屏 |
| P | 播放烟花；第一人称保持当前视角，模型模式切到烟花取景，再按可结束 |
| Esc | 第一人称释放鼠标以操作界面；模型模式恢复界面并返回全景 |

第一人称界面提供「导览」「帮助」及返回模型的按钮。触屏设备提供方向、跑步、跳跃、交互与烟花按钮，并支持拖动环顾；推荐用桌面键鼠体验完整操作。

## 项目游玩规则

1. 从大门外前庭步行入园，使用导览找到设施。
2. 靠近对应 VIP 门按 F 打开，再实际走过通道和台阶到座位旁。普通排队区和 VIP 入口分开，玩家使用本地园主角色。
3. 非摩天轮项目靠近空座按 F 入座：碰碰车共有 8 辆可选，过山车为 6 排、每排左右两座，共 12 个可选座位。驾驶输入、视角和离车位置跟随所选车辆或座位。
4. 五位同伴随机选择剩余空位，沿可通行路线走来并逐一入座。等待不计入项目运行时长；门关闭后按 Enter 启动。运行中不能提前离座，准备就绪时可按 F 取消乘坐。
5. 等设施停稳后按 F 离座。同伴从实际停止的座位下车并步行离开；若要开始另一个项目，需先等其离开前一设施。

| 项目 | 实际流程与时长 |
| --- | --- |
| 摩天轮 | 12 个保持水平的座舱，持续慢转。低位舱门打开时直接走入，舱内 WASD 移动、F 坐下/起身；累计一圈约 96.7 秒后，等到站开门再起身走出。无需 Enter，不安排同伴同舱 |
| 旋转木马 | 可选附近木马，跨坐后等待同伴。Enter 启动，约 60 秒运行并留约 2 秒减速余量；停稳后从当前马匹旁下马，保留转盘停止角度 |
| 海盗船 | 入座后等待同伴并按 Enter。约 60 秒，前段逐渐起摆、中段保持、后段收摆；高处慢、最低点快，停稳后离座 |
| 苍龙过山车 | 闭合轨道约 267.5 场景单位、高约 29.1 单位；选择空座、等待同伴、Enter 启动。完整一圈约 56 秒，回站制动后离座，不按固定时长截断轨道 |
| 碰碰车 | 约 18.7 × 15.8 场景单位场地，8 辆车。选择空车，等同伴驾驶其他车辆后按 Enter；手动驾驶约 60 秒并平顺制动，从当前停车位置下车，车辆不重新归位 |

尺寸均为场景单位，并非现实设施的工程尺寸。碰碰车采用固定 120 Hz 的二维刚体模拟，包含胶囊形保险杠、摩擦、碰撞转矩和乘客惯性，玩家与 NPC 共用物理模型。轨道使用平滑闭合曲线，游客寻路使用高度感知 A*；浏览器中由模块 Worker 计算路径，保留同一角色的登乘和离座动作。

## 测试方法

在仓库根目录执行完整自动化检查：

```sh
npm test
```

也可逐项运行；所有脚本仅使用 Node.js 和仓库内资源：

| 命令 | 覆盖内容 |
| --- | --- |
| `node scripts/verify-bumper-physics.mjs` | 碰撞、动量与能量、侧撞转矩、墙体、拥堵、乘客惯性和帧率独立性，包含 120 秒模拟 |
| `node scripts/verify-ride-motion.mjs` | 轨道闭合与切线/倾斜连续性、列车速度、海盗船摆动与能量稳定性 |
| `node scripts/verify-first-person.mjs` | 行走碰撞、跑跳、五个项目的状态及完整周期 |
| `node scripts/verify-navigation.mjs` | 同伴路径避开车辆、栏杆与高度障碍 |
| `node scripts/verify-landscaping.mjs` | 13 处绿地落地、步行/跑步/跳跃进出、圆角与树干碰撞 |
| `node scripts/verify-ambient-walkers.mjs` | 五位同伴及配色、39 位排队游客、路线障碍、15 分钟行走与前进朝向 |
| `node scripts/verify-clearance.mjs` | 摩天轮相邻座舱距离、树冠与列车/座舱整圈运行净空 |
| `node scripts/verify-playthrough.mjs` | 构建实际场景，无图形运行四个项目的同伴登乘/运行/离座流程，以及摩天轮入舱、走动、坐下、起身和离舱 |
| `node scripts/verify-seat-selection.mjs` | 8 辆碰碰车、12 个过山车座位、随机剩余空位、6 张长椅的 18 种靠近方式、第一人称坐姿和双手落点 |
| `node scripts/verify-companion-return.mjs` | 切换项目后保留同伴实际等候位置与状态 |

完整测试还会间接执行 `verify-expansion.mjs` 和 `verify-park-access.mjs`，检查五个普通/VIP 入口、角色规则及高架站台可达性；也可单独运行这两个脚本。`verify-expansion.mjs` 会根据模型重新生成 `dist/ride-layout.json`，测试后可用 `git diff` 查看是否存在布局变化。

这些检查验证场景数据、运动和交互逻辑，不能代替浏览器画面检查。人工验收建议覆盖：两种模式与左侧菜单、H 隐藏/恢复、F 交互、P 烟花、长椅低头坐姿、同伴行进朝向和停稳下车，以及各项目的键鼠操作与视觉效果。

## 录屏指南

[VIDEO-SHOT-LIST.md](VIDEO-SHOT-LIST.md) 提供 **55 秒、9:16 竖屏**分镜，建议输出 1080 × 1920。主题从俯瞰微缩园区，到与五位同伴一起乘坐过山车和驾驶碰碰车，最后以烟花收尾。

- 调整好取景，再按 H 隐藏界面；F 交互、Enter 启动、P 放烟花。
- 先试录 10 秒确认流畅，稳定帧率优先；各段前后多录约 2 秒。
- 过山车和碰碰车各完整录一趟，再剪出爬升、下坠、弯道、选车和碰撞片段；等候与登乘时间可剪短，分镜的 55 秒是剪辑成片时长。
- 烟花单独取景，切回模型后等待镜头移动完成。音乐与后期音效需自行准备并确保有权使用；当前场景没有内置轮轨声等录屏音效。

分镜文档是拍摄与剪辑方案，仓库未提供已录制或生成的成片。

## 已知限制

- 当前为单人网页体验；五位同伴是本地 NPC，没有多人联机、存档或独立服务端账号系统。VIP 是本地园主角色规则，不代表站点访问权限或服务端授权。
- 人物、动作、材质与园林主要由程序生成，采用风格化关节动画，不是动作捕捉或写实扫描。步行碰撞为高度分层的简化形状，不是全场景三角网格刚体模拟。
- 普通排队游客作为园区队列保留；本轮随玩家登乘的是五位固定同伴，尚未实现完整的普通游客排队轮转、票务或运营系统。
- 同伴会真实寻路和避让，登乘时间取决于当前位置及拥堵；无法找到可行路径时等待，界面会提示离座重试，不能直接跳过入座过程启动。
- WebGL、设备性能、屏幕比例和浏览器输入能力会影响画面及流畅度；触屏和拖动环顾可作为备用操作，自动化无图形测试不覆盖 GPU 渲染、浏览器鼠标锁定或真机录屏体验。
